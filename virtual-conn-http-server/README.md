# virtual-conn-http-server

これは、HTTP 通信を仮想的にシミュレートするためのテストコードです。

`net/http`と`google.golang.org/grpc/test/bufconn`を使用して、実際のネットワークポートを使わずに HTTP 通信を行います。このアプローチにより、ローカル環境での高速で安全なテストが可能になります。

## 概要

このリポジトリでは、Go の標準パッケージ`net/http`と`bufconn`を使って仮想的な HTTP サーバーを立ち上げ、HTTP 通信を実際のネットワークポートを利用せずに行うテストコードを実装しています。

`bufconn`は、仮想的なネットワーク接続を提供するためのライブラリで、テスト環境でネットワーク依存性をなくすために便利です。このコードでは、`bufconn`を使って仮想リスナーを作成し、そのリスナー上で HTTP サーバーとクライアントを接続しています。

## 主な内容

- **HTTP サーバーの起動**: 仮想リスナー上で HTTP サーバーを起動し、テスト用のハンドラを使ってリクエストに応答します。
- **並列テストの実行**: `t.Parallel()`を使って並列に複数のサブテストを実行し、HTTP サーバーが複数のリクエストを同時に処理できることを確認します。
